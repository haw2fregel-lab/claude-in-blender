# 一発の操作 ＋ あとで効き具合を調整

## 使う時

「この操作をかけて」と頼まれた時。**処理はこちらが書き、どれだけ効かせるかはユーザーが握る**——「スケールを大きくして」なら倍率だけ、「膨らませて」なら量だけを露出して、**動かせる状態で渡す**。一度で当てるより、ユーザーが手で当てるほうが速い。

こちらは一発で決める操作向け。ゼロから形を作って数値で詰め続けるなら Skill `blender-param-panel`（ジェネレーター）、既存メッシュへ変形を掛け続けるなら Skill `blender-modifier-inject`。

## 組み立て

`bpy.types.Operator` と、そのボタンを置くだけの `Panel` の2クラスを1スクリプトで登録する（再実行に備え unregister → register）。

- F9 調整と Ctrl+Z は、`bl_options = {'REGISTER', 'UNDO'}` があって初めて効く
- 調整させたい値だけ `bpy.props` のプロパティにする。**調整 UI は Blender が自動で作る**——スライダーもドロップダウンも、パネルコードなしで、プロパティを足せばそのまま増える
- `poll` は「MESH である」と「オブジェクトモードである」の両方を見る——`me.vertices` への書き込みが反映されるのはオブジェクトモードだけ。`cls.poll_message_set("...")` でグレーアウトの理由がホバーに出る
- `execute` で頂点を書き換えたら `me.update()`。`self.report({'INFO'}, ...)` で効いた頂点数を出す
- **`v.co *= amount` は原点基準**。重心基準・法線方向が期待される時は `v.co = center + (v.co - center) * amount` と基準を明示する

## 実行はボタンから

調整パネルが出るのは、ボタン・メニュー・ショートカット（`INVOKE_DEFAULT`）経由の実行だけ——redo 情報はそこで登録され、左下のパネルはその登録を見ている。Python からの `bpy.ops.xxx()` は `EXEC_DEFAULT` で走る。**スクリプトを流して操作を渡す時は、ボタンを置くまでがセット**——ユーザーが押す1回目から F9 が効く。

ユーザーへは、ボタンの場所と、左下に出ることの両方を言う:

> **サイドパネル（N キー）のボタンを押してください。3Dビュー左下に折りたたみパネルが出て、そこで値を動かせます（F9 でも開きます）。**

## 効かせる範囲

**オブジェクトモードでも `v.select` は読める**。編集モードで選択してからオブジェクトモードに戻れば、選択は保たれている。面・辺も同じ（`polygons[i].select` / `edges[i].select`）。編集モードのまま効かせる時は `bmesh.from_edit_mesh` を使う。

「選択した所を」と言われたら選択を尊重し、何頂点に効いたか報告する。

## 累積の罠

スクリプトから連続で呼ぶ時は、間に `bpy.ops.ed.undo()` を挟む——倍率 2.0 を undo なしで2回呼ぶと [2,2,2] → [4,4,4] → **[8,8,8]** と積む。調整パネルでの変更は直前の1操作だけ undo してから再実行するので、その分は積まない。絶対値の指定・位置合わせの性質は、元の値から計算する形で書く。

`未確認`: 調整パネル経由で積まないことの厳密な切り分けは未取得（実用上の問題なし）。確かめるには倍率を「何もしない値」に戻し、直前の状態が復元されるかを見る。

## 罠

| 罠 | 症状 | 対処 |
| --- | --- | --- |
| `bl_options` に `'UNDO'` なし | 調整パネルが出ない・Ctrl+Z で戻らない | 必ず入れる |
| スクリプトから `bpy.ops` で実行 | 調整パネルが出ない | ボタンを置いて、ユーザーに押してもらう |
| `undo` を挟まず連続実行 | 効果が累積する（2倍×2回＝8倍） | 間に `bpy.ops.ed.undo()`、または元の値から計算する形へ |
| 編集モードで `me.vertices` に書く | 反映されない | `poll` でモードを弾く。編集モードで効かせるなら `bmesh.from_edit_mesh` |
| クラス名 | `does not contain '_OT_'` 警告 | `PREFIX_OT_name` / `PREFIX_PT_name` にする |
| `bl_rna.properties` で prop を確認 | 定義したプロパティが出ない | `bpy.ops.<mod>.<op>.get_rna_type().properties` で読む |
| `dimensions` で結果を検算 | 変形したのに値が変わらない | depsgraph 待ち。**頂点座標の min/max から直接計算する** |

## 渡す前に・境界

- **効いたことを数値で示す**——変形前後の寸法・頂点数を出す。**F9 で調整できることも伝える**——ユーザーは F9 を知らないことが多い
- 頂点の削除・マージ・トポロジ変更は、対象数を報告してから実行するか、ユーザーの確認を取る
- **ファイルの保存・書き出しは印鑑を待つ。** メッシュを変えるところまでがこの形の範囲
- 同じ操作を繰り返し使いたいと言われたら、置き場を相談する（一時ファイルの寿命は Blender を閉じるまで）
